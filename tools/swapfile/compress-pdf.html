Compress PDF

Reduce a PDF's file size so it's easier to email or upload. Pages render as images to shrink size, so this works best on scanned documents or image-heavy PDFs rather than dense text files.

Drop a PDF here, or click to browse

Shrinks file size — pages become images, so text is no longer selectable

    How it works

    1. Drop or choose a PDF file.
    2. Press Convert to compress it.
    3. Download the smaller PDF.

    Common questions

    Will the text still be selectable afterward?
    No — compression rasterizes each page into an image, so text is no longer selectable or searchable. It suits scanned or image-heavy PDFs best.
    How much smaller will my file get?
    It depends on the original — image-heavy PDFs shrink the most; the exact size shows after conversion.
